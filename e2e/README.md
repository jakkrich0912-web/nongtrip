# เทสต์ใช้งานจริงผ่านเบราว์เซอร์ (Playwright)

เปิดเว็บจริง แล้วกดใช้งานเหมือนผู้ใช้: หน้าข้อมูล ค้นรอบที่พัก ตัวกรองรัศมี สมัครและเมนูบัญชี เปลี่ยนรหัสผ่าน
ออกจากระบบแล้วคุกกี้เดิมใช้ไม่ได้ สถานที่โปรด แชต แดชบอร์ดผู้ดูแล และหน้าจอมือถือ

```bash
docker compose up -d --build --wait          # เปิดระบบก่อน (ตั้ง ADMIN_EMAILS ใน .env ถ้าจะเทสต์แดชบอร์ด)
cd e2e && npm install && npx playwright install chromium
E2E_ADMIN_EMAIL=e2e-admin@example.com npx playwright test
```

- `E2E_BASE_URL` ที่อยู่ของเว็บ ค่าเริ่มต้น `http://localhost:8080`
- `E2E_ADMIN_EMAIL` ต้องอยู่ใน `ADMIN_EMAILS` ของระบบ ไม่ตั้งจะข้ามเทสต์แดชบอร์ดฝั่งผู้ดูแล
- เทสต์สร้างบัญชีอีเมลสุ่มทุกครั้ง รันซ้ำบนฐานข้อมูลเดิมได้ แต่สมัครได้ไม่เกิน 20 ครั้งต่อชั่วโมงต่อ IP
- CI รันชุดนี้ต่อจาก smoke test ในงาน docker ผลล้มเหลวมีรายงานพร้อมภาพและ trace ให้ดาวน์โหลด
