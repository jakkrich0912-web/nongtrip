# scripts

สคริปต์ช่วยงาน

- `build_places.py` สร้างข้อมูลสถานที่ทั้ง 77 จังหวัดจาก Wikipedia (ต้องมีอินเทอร์เน็ต ใช้ `python scripts/build_places.py`) ใช้ `seed_places.py` เป็นรายชื่อตั้งต้น
- `smoke_test.py` (ทดสอบเร็วว่าระบบที่รันอยู่ตอบได้) จะเพิ่มเมื่อมีบริการพร้อม
- `check_llm.py` ตรวจว่า `LLM_PROVIDER`/คีย์/รุ่นใน `.env` เรียก LLM ได้จริง (เรียก 1 ครั้ง ไม่พิมพ์คีย์) ดู `docs/RUNBOOK.md` หัวข้อเปิดโหมด LLM
- `eval_retrieval.py` วัด Hit@3 ของตัวค้นคืนอย่างเดียว (ไม่ใช้ LLM)
- `eval_rag.py` วัดครบวงจร ค้นคืน -> LLM -> ด่านตรวจ แยกตามชนิดคำถาม (มีคำตอบ/ไม่มี/ถามราคา/พยายามสั่งระบบ) รูปแบบชุดคำถามอยู่ในหัวไฟล์
