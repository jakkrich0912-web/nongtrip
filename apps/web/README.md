# apps/web

หน้าเว็บ 4 หน้า: หน้าแรก, ค้นหา, แชตบอท, ล็อกอิน (ดู `docs/SPEC.md`) ใช้ React + Vite + Leaflet

## รัน

```bash
cd apps/web
npm install
npm run dev      # http://localhost:5173
npm test         # เทสต์ระยะ รัศมี 30 กม. ตัวตรวจผลค้น และการค้นที่พักรอบหมุด
```

## สถานะ

- หน้าแรก: เลือกจังหวัด 77 จังหวัด ✅
- ค้นหา: ปักหมุดบนแผนที่ เห็นสถานที่ที่ตรวจที่มาแล้วใน 30 กม. เรียงใกล้ไปไกล เส้นตรง ตัวกรองประเภท ลิงก์ Google Maps ✅ (ค้นด้วยชื่อที่พัก + ข้อมูล OSM รอ API)
- ค้นหาโหมด "ยังไม่ได้จอง": ปักหมุดย่าน แสดงการ์ดที่พักรอบหมุดจาก `GET /api/lodgings/near` ✅
- ค้นที่พักจากชื่อ `GET /api/lodgings/search` พร้อมตัวกรองจังหวัด ย่าน ประเภท พบหลายแห่งให้ผู้ใช้เลือกเอง ไม่เลือกให้แม้เจอแห่งเดียว ✅
- ค้นหาโหมด "มีที่พักแล้ว": สถานที่รอบที่พักจาก `GET /api/places/nearby` ครั้งละ 100 แห่ง กรองที่เที่ยว/คาเฟ่ ✅ ถ้าเปิด API ไม่ได้ใช้สถานที่ที่ตรวจที่มาแล้วในเครื่องแทนและแจ้งผู้ใช้
- หน้ารายละเอียดสถานที่ `/places/:id` (`GET /api/places/{id}`) ซ่อนส่วนที่ไม่มีข้อมูล มีที่มาของข้อมูลและที่เที่ยวใกล้เคียง ✅
- หน้าจังหวัด `/provinces/:ชื่อ` (`GET /api/provinces/{ชื่อ}/places`) กรองประเภท โหลดเพิ่ม และบอกเมื่อจังหวัดยังไม่มีข้อมูล ✅
- แชตบอท: หน้าตาพร้อม รอเชื่อม `POST /api/chat`

## เชื่อม API

ตอน `npm run dev` Vite ส่งต่อ `/api` ไปที่ `http://localhost:8000` (รัน API ด้วย `python -m uvicorn services.api.main:app --port 8000` จากรากรีโป) เปลี่ยนได้ด้วยตัวแปร `VITE_API_URL` รูปแบบ API ดู `docs/CONTRACT.md` ข้อ 3

ข้อมูลตอนนี้อ่านจาก `services/places/data/` ผ่าน `src/lib/data.js` เมื่อ API พร้อมแก้เฉพาะไฟล์นั้น
