# services/api

ประตูเดียวที่หน้าเว็บคุยด้วย (FastAPI) เรียกบริการค้นหา `services/places` และตรวจผลทุกครั้งด้วยตัวตรวจอิสระ

## รัน

```
pip install -r services/api/requirements.txt
python -m uvicorn services.api.main:app --port 8000
```

เปิด http://localhost:8000/docs ดูเส้นทางทั้งหมดและลองเรียกได้ เส้นทางและรูปแบบคำตอบอยู่ใน `docs/CONTRACT.md`

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `main.py` | เส้นทาง API (`create_app`) แปลงข้อผิดพลาดของคำขอเป็น HTTP 400 ข้อความไทย |
| `auth.py` | แฮชรหัสผ่าน (scrypt) เซสชันคุกกี้ที่เซ็นด้วย HMAC ตัวจำกัดการเดารหัสผ่าน |
| `chat.py`, `chat_rules.py` | แชตบอทแบบกฎ `POST /api/chat` (SSE) ตัวแปลงข้อความอยู่ใน `chat_rules.py` |
| `store.py` | ฐานข้อมูล SQLite: ผู้ใช้ ประวัติที่พัก สถานที่โปรด แชต |
| `google.py` | ตรวจ Google ID token (ให้ Google ตรวจลายเซ็น แล้วตรวจ aud/iss/exp/อีเมลยืนยัน) |
| `guide.py` | ไกด์ที่เที่ยวจากสถานที่ที่ตรวจที่มาแล้ว (หน้าแรก หน้าจังหวัด รายละเอียดสถานที่) ไม่เปิดเผยราคา |
| `accounts.py` | เส้นทาง `/api/auth/*` และ `/api/me/*` รวมลบข้อมูลทั้งหมดและลบบัญชี (ผู้ที่ไม่ล็อกอินไม่ถูกบันทึกอะไร) |
| `validator.py` | ตัวตรวจอิสระ ไม่ใช้โค้ดค้นหาร่วมกัน คำนวณระยะ ตรวจเรียงลำดับ รัศมี ซ้ำ ฟิลด์ต้องห้าม ป้ายแหล่งข้อมูล |
| `tests/` | เทสต์ตัวตรวจ (ทดลองทำผลให้ผิดแล้วต้องจับได้) และเส้นทาง API |

ตัวแปร env: `OSM_LIVE`, `PLACES_CACHE_DIR`, `OSM_SNAPSHOT_DIR`, `SESSION_SECRET`, `SESSION_SECURE` (ตั้ง 0 ตอนพัฒนาบน http), `GOOGLE_CLIENT_ID` (ล็อกอินด้วย Google), `DB_PATH` (ดู `.env.example`) และ `WEB_ORIGINS` (ถ้าไม่ตั้งอนุญาตทุกที่มา ใช้ตอนพัฒนา)

## สถานะ

เสร็จ: ค้นที่พักจากชื่อ ค้นสถานที่รอบจุด ค้นที่พักรอบหมุด จังหวัดและจุดกลาง ตัวตรวจอิสระ
เสร็จเพิ่ม: ผู้ใช้/ล็อกอิน, ประวัติที่พัก, สถานที่โปรด, ประวัติแชต (ฝั่งอ่านและลบ)
เสร็จเพิ่ม: แชตบอทแบบกฎ (`/api/chat`) ยังไม่ทำ: โหมด LLM
