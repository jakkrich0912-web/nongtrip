# น้องทริป: ค้นสถานที่เที่ยวและคาเฟ่รอบที่พักทั่วไทย

เว็บที่ให้พิมพ์ชื่อที่พักที่จองไว้ (หรือปักหมุดบนแผนที่) แล้วแสดงสถานที่เที่ยวและคาเฟ่ในรัศมี 30 กม. เรียงจากใกล้ไปไกล พร้อมแผนที่และเส้นทาง ใช้ได้ทั้ง 77 จังหวัด มีผู้ช่วยแชตบอทและระบบล็อกอิน

> **สถานะ (4 พ.ย. 2569): ใช้งานได้ครบตาม SPEC อยู่ช่วงเก็บงานก่อนเดโม** หน้าเว็บ บริการค้น API ล็อกอิน แชตบอท (กฎ + LLM พร้อมที่มา) ตัวตรวจผลค้น และฟีเจอร์ชุดสุดท้าย (หน้าแชตแบบใหม่ โหมดมืด LLM สำรอง หน้าข้อมูล ตั้งค่าบัญชี แดชบอร์ดผู้ดูแล) รวมอยู่ใน `develop` แล้ว เทสต์ Python 639 ข้อ หน้าเว็บ 133 ข้อ และเทสต์ใช้งานจริงผ่านเบราว์เซอร์ 19 ข้อผ่าน หลังจากนี้แก้บั๊กเท่านั้น

**กฎข้อมูล:** ทุกค่าต้องมาจากแหล่งจริง ไม่เดา ค่าที่ไม่ทราบเป็น `null` และระบบบอกผู้ใช้ ไม่จองหรือชำระเงินแทนผู้ใช้ ไม่แสดงราคาหรือค่าเข้า ไม่มีรีวิวในระบบ (ลิงก์ไปดูที่ Google Maps)

## 1. ทำอะไรได้บ้าง

หน้าหลัก 4 หน้าตาม [`docs/SPEC.md`](docs/SPEC.md) และหน้าเสริม ทุกหน้าสลับภาษาไทย/อังกฤษได้

- **หน้าแรก:** แนะนำระบบ เลือกจังหวัดจาก 77 จังหวัด
- **ค้นหา:** ค้นด้วยชื่อที่พักหรือปักหมุด ดูสถานที่เที่ยวและคาเฟ่เรียงใกล้ไปไกล แผนที่ เส้นตรงจากที่พัก ปุ่มนำทางด้วย Google Maps กรองตามประเภทและรัศมี ชื่อที่พักซ้ำให้ผู้ใช้เลือกเอง ถ้ายังไม่ได้จองที่พัก ปักหมุดแล้วดูที่พักรอบหมุด พร้อมสถานที่เที่ยวของแต่ละที่พัก
- **แชตบอท:** ผู้ช่วยตอบคำถามและค้นสถานที่ ใช้เครื่องมือค้นตัวเดียวกับหน้าค้นหา ตอบเรื่องสถานที่จากคลังความรู้ Wikipedia พร้อมที่มา (RAG) มีด่านตรวจคำตอบในโค้ด ถ้าไม่มีคีย์ LLM ใช้โหมดกฎ
- **ล็อกอิน:** สมัครและเข้าสู่ระบบ (อีเมล/รหัสผ่าน หรือ Google ถ้าตั้ง `GOOGLE_CLIENT_ID`) บันทึกประวัติที่พักที่ค้น สถานที่โปรด ประวัติแชต และลบข้อมูลของตัวเองได้
- **แชตแบบแอปแชต:** ประวัติแชตแบ่งตามวัน แก้คำถาม ถามใหม่ ให้คะแนน 👍👎 ตอบคำถามนอกเรื่องได้พร้อมคำเตือน และตั้งผู้ให้บริการ LLM สำรองได้ (`LLM_FALLBACK`)
- **หน้าเสริม:** ทริปของฉัน ตั้งค่าบัญชี (เปลี่ยนรหัสผ่าน ออกจากระบบอุปกรณ์อื่น) ทุกจังหวัด หน้าจังหวัด รายละเอียดสถานที่ เกี่ยวกับเรา ความเป็นส่วนตัว และหน้าไม่พบหน้า
- **แดชบอร์ดผู้ดูแล:** ยอดรวมการใช้งาน กราฟแชตและการค้นรายวัน เหตุที่ด่านตรวจตีตก ความครอบคลุมข้อมูล (เฉพาะอีเมลใน `ADMIN_EMAILS` ไม่มีข้อมูลรายคน)
- **อื่น ๆ:** โหมดมืดทั้งเว็บ เมนูบัญชีที่หัวเว็บ มาสคอตน้องทริปกับหน้าต่างแชตลอย

## 2. โครงสร้างระบบ

```
apps/web/          หน้าเว็บ
services/api/      ผู้ใช้ ประวัติ แชตบอท ตัวตรวจผลค้น (ประตูเดียวที่เว็บคุยด้วย)
services/places/   ค้นที่พักและสถานที่รอบจุด (OpenStreetMap + ข้อมูลที่ตรวจที่มาแล้วใน data/)
docs/              CONTRACT, SPEC, RUNBOOK, DEMO_SCRIPT, DATA_SOURCES, GIT_FLOW
scripts/           สคริปต์ช่วยงาน (รวม smoke_test.py)
docker-compose.yml เปิดทั้งระบบด้วย `make up` (web + api) ดู docs/RUNBOOK.md
.github/           CODEOWNERS, PR template, CI
```

หลักออกแบบ: LLM ใช้ด้านภาษาและเลือกเครื่องมือ ส่วนข้อเท็จจริงและระยะทางมาจากโค้ดและข้อมูลเท่านั้น และมีตัวตรวจอิสระตรวจผลก่อนแสดง ข้อตกลงกลางอยู่ที่ [`docs/CONTRACT.md`](docs/CONTRACT.md)

## 3. แหล่งข้อมูลภายนอก

## 9. ผลวัด

ตัวเลขทุกตัวมาจากการรันจริง ห้ามใส่ตัวเลขที่ไม่ได้วัด

**ค้นรอบที่พัก** ทดสอบค้นจริง 12 จังหวัด (3 พ.ย. ใช้สแนปช็อต OSM) ทุกจังหวัดผลเรียงใกล้ไปไกล อยู่ใน 30 กม. ไม่ซ้ำ และผ่านตัวตรวจ รายละเอียดใน [`docs/COVERAGE.md`](docs/COVERAGE.md) หัวข้อ "ผลทดสอบค้นจริง"

**แชตตอบคำถามด้วย LLM (RAG)** ชุดคำถาม 200 ข้อ รันกับ claude-sonnet-5-5 รอบที่ 3 (2 พ.ย.)

| ชนิดคำถาม | จำนวน | ผ่าน |
|---|---|---|
| answer (ต้องตอบโดย LLM และผ่านด่านตรวจ) | 160 | 85.6% (รอบที่ 1 ได้ 83.8% จึงรายงานเป็นช่วงประมาณ 84-86%) |
| no_answer (นอกขอบเขต) | 20 | 100% |
| refuse (ถามราคา รีวิว จอง) | 12 | 100% |
| injection (พยายามสั่งระบบ) | 8 | 100% |

ตัวค้นคืนหาก้อนที่ถูกใน 3 อันดับแรก 158 จาก 160 ข้อ (98.8%) คำถามเขียนโดยทีม ไม่ใช่ผู้ใช้จริง รายละเอียดและข้อควรรู้ใน [`docs/RAG_EVAL.md`](docs/RAG_EVAL.md)

**เทสต์อัตโนมัติ** (4 พ.ย.) เทสต์ Python 639 ข้อ (`make test`) เทสต์หน้าเว็บ 133 ข้อ (CI job `web`) และเทสต์ใช้งานจริงผ่านเบราว์เซอร์ด้วย Playwright 19 ข้อ (`e2e/` รันใน CI job `docker` กับระบบที่เปิดด้วย Docker) ผ่านทั้งหมด

## 10. ปัญหาที่เจอและข้อจำกัด

### 10.1 ปัญหาที่เจอระหว่างเตรียมข้อมูล

- ผลค้นหา Wikipedia จับคู่สถานที่ผิดได้ พบด้วยการเทียบพิกัดกับกลุ่มของจังหวัดแล้วตัดออก
- ฐานข้อมูลสถานที่บางจังหวัดมี 1-2 แห่ง และยโสธรกับอ่างทองยังไม่มีเลย
- LLM บางครั้งใส่ชื่อสถานที่ที่ไม่อยู่ในผลค้นหรือลืมรหัสที่มา ด่านตรวจตีตกแล้วระบบถอยไปตอบแบบกฎ (ราว 14-16% ของข้อ answer)
- Overpass สาธารณะช้าหรือจำกัดความถี่บ่อย จึงดึงสแนปช็อตเก็บไว้ล่วงหน้า

### 10.2 ข้อจำกัด (ที่รู้แล้ว)

- ข้อมูลจาก OpenStreetMap มีแค่ชื่อ ประเภท พิกัด ไม่ครบทุกแห่ง คุณภาพต่างกันตามพื้นที่
- ระยะเป็นเส้นตรง ไม่ใช่ระยะขับรถ
- สแนปช็อต OSM ครบ 77 จังหวัด
- คำอธิบายสถานที่มีเฉพาะ 11 แห่งในเชียงใหม่ ที่เหลือแสดงว่าไม่ทราบ
- ผู้ดูแลระบบกำหนดด้วยอีเมลใน `ADMIN_EMAILS` และระบบยังไม่ยืนยันอีเมลตอนสมัคร ต้องสมัครบัญชีผู้ดูแลก่อนเปิดเว็บให้คนอื่นใช้
- ผลวัด RAG วัดกับ claude-sonnet-5-5 ก่อนการปรับแชตรอบล่าสุด ถ้าใช้ผู้ให้บริการสำรองต้องวัดใหม่ก่อนอ้างตัวเลข
