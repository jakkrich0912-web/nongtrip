# แบ่งงาน

หลักการ: Jakkrich เป็นเจ้าของงานแกนหลัก (ค้นหา, API, ตัวตรวจ, แชทบอท, หน้าค้นหา) และเป็นคนรีวิวทุก PR
Jirapa ทำงานที่แยกออกมาได้ชัด ไม่ต้องรอโค้ดแกน โดยใช้ข้อมูลตัวอย่างตาม `docs/CONTRACT.md` ไปก่อน

## ใครทำอะไร

| โมดูล | โฟลเดอร์ | เจ้าของ | ผู้ช่วย |
|---|---|---|---|
| ค้นสถานที่ใกล้ที่พัก (OSM + ข้อมูลที่ตรวจแล้ว, ระยะ, เรียงใกล้ไปไกล, cache) | `services/places` | Jakkrich | - |
| API กลาง, ตัวตรวจอิสระ, แชทบอท (เรียกเครื่องมือค้นหาเดียวกัน) | `services/api` | Jakkrich | - |
| ล็อกอิน, ประวัติการค้น, สถานที่โปรด, ประวัติแชท (ฝั่ง API + ฐานข้อมูล) | `services/api` | Jakkrich | Jirapa ช่วยเขียนเทสต์ |
| หน้าค้นหา + แผนที่ + ปุ่ม Google Maps | `apps/web` | Jakkrich | - |
| หน้าแชทบอท | `apps/web` | Jakkrich | - |
| หน้าแรก (โชว์ระบบ, เลือกจังหวัด 77 จังหวัด) | `apps/web` | Jirapa | Jakkrich ตกลงดีไซน์กลาง |
| หน้าล็อกอิน/สมัคร และหน้าประวัติ/สถานที่โปรด (ฝั่งหน้าจอ) | `apps/web` | Jirapa | Jakkrich ทำ API ให้ |
| ข้อมูลที่ตรวจแล้ว: ตรวจ/เพิ่มสถานที่ใน `places.json` และเช็กความถูกต้อง | `services/places/data`, `scripts` | Jirapa | Jakkrich เขียนสคริปต์ตรวจ |
| ชุดทดสอบ/ผลวัด (เคสค้นหาจริง 10-15 จังหวัด) | `docs/COVERAGE.md`, `tests` | Jirapa | Jakkrich |
| สไลด์, DEMO_SCRIPT, ซ้อมพูด | `docs`, สไลด์ | ทั้งคู่ | Jakkrich เรียบเรียงภาพรวม |

## ลำดับพึ่งพา

1. วันที่ 1: Jakkrich ล็อก `docs/CONTRACT.md` (รูปแบบ request/response) เป็นอย่างแรก เพื่อให้ Jirapa เริ่มหน้าเว็บโดยใช้ข้อมูลตัวอย่างได้ทันที
2. หน้าเว็บของ Jirapa เรียก API ผ่านค่าตั้ง `API_BASE_URL` เดียว ตอนแรกชี้ไปข้อมูลตัวอย่าง ภายหลังสลับมาเรียกของจริง
3. ตัวตรวจ (validator) เขียนแยกจากบริการค้นหา ห้ามใช้โค้ดค้นหาร่วมกัน

## แผน 5 วัน

| วัน | Jakkrich | Jirapa |
|---|---|---|
| 1 | CONTRACT + บริการค้นหา (OSM, ข้อมูลที่ตรวจแล้ว, เรียง, cache) พร้อมเทสต์ | โครงหน้าเว็บ + หน้าแรกจากข้อมูลตัวอย่าง |
| 2 | หน้าค้นหา + แผนที่ + ตัวตรวจ | ตรวจข้อมูลที่ตรวจแล้ว, หน้าล็อกอิน/สมัคร (หน้าจอ) |
| 3 | แชทบอท + ต่อ API เข้ากับหน้าเว็บ | หน้าประวัติ/สถานที่โปรด, เชื่อมหน้าแรกกับ API จริง |
| 4 | ล็อกอิน/ประวัติ (ฝั่ง API), ผลวัด | ชุดทดสอบ 10-15 จังหวัด, ปรับ UI |
| 5 | ซ้อมบนอินเทอร์เน็ตจริง, วิดีโอสำรอง | สไลด์, DEMO_SCRIPT, ซ้อมพูด |

ถ้าเวลาไม่พอ ตัดตามลำดับนี้: การบันทึกประวัติ/สถานที่โปรด ก่อน, แล้วค่อยแชทบอท LLM (เหลือแบบกฎ) ห้ามตัดการค้นหาหลัก
