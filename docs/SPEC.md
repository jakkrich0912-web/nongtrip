# SPEC: น้องทริป

## เป้าหมาย

ผู้ใช้พิมพ์ชื่อที่พักที่จองไว้ แล้วเห็นสถานที่เที่ยวและคาเฟ่ในรัศมี 30 กม. เรียงจากใกล้ไปไกล พร้อมแผนที่และเส้นทาง ใช้ได้ทั้ง 77 จังหวัด

## เว็บ 4 หน้า

| หน้า | ทำอะไร |
|---|---|
| หน้าแรก | แนะนำระบบ ช่องเลือกจังหวัด 77 จังหวัด |
| ค้นหา | ค้นด้วยชื่อที่พักหรือปักหมุด แสดงรายการ แผนที่ เส้นทาง ตัวกรองประเภท |
| แชตบอท | ผู้ช่วยตอบคำถามและค้นสถานที่ ใช้เครื่องมือค้นตัวเดียวกับหน้าค้นหา |
| ล็อกอิน | สมัครและเข้าสู่ระบบด้วยอีเมลกับรหัสผ่าน |

หน้าเสริม (เพิ่มภายหลัง)

| หน้า | ทำอะไร |
|---|---|
| ทริปของฉัน `/me` | ประวัติที่พักที่ค้น สถานที่โปรด ประวัติแชต ลบข้อมูลและลบบัญชี |
| ตั้งค่าบัญชี `/settings` | ข้อมูลบัญชี เปลี่ยนรหัสผ่าน ออกจากระบบอุปกรณ์อื่น |
| รายละเอียดสถานที่ `/places/:id` และจังหวัด `/provinces/:ชื่อ` | ข้อมูลที่มีจริงพร้อมที่มา |
| ทุกจังหวัด `/provinces` | 77 จังหวัดจัดตามภาค ค้นชื่อไทยหรืออังกฤษ พร้อมจำนวนสถานที่ที่ตรวจแล้ว |
| เกี่ยวกับเรา `/about` | หลักการ แหล่งข้อมูลพร้อมสัญญาอนุญาต ตัวเลขความครอบคลุมจากระบบจริง ทีม |
| ความเป็นส่วนตัว `/privacy` | ข้อมูลที่เก็บ ข้อมูลที่ส่งออกนอกระบบ คุกกี้ log วิธีลบ (ข้อความต้องตรงกับโค้ด แก้โค้ดแล้วแก้หน้านี้ด้วย) |
| ไม่พบหน้า | ลิงก์ผิดแสดงหน้านี้ แทนการเด้งกลับหน้าแรก |

## การค้น 2 โหมด

1. **มีที่พักแล้ว:** พิมพ์ชื่อที่พักหรือปักหมุด ระบบแสดงสถานที่เที่ยวและคาเฟ่ในรัศมี 30 กม. เรียงใกล้ไปไกล
2. **ยังไม่ได้จอง:** ปักหมุดหรือพิมพ์ชื่อย่าน ระบบแสดงที่พักรอบหมุด (เริ่มที่ 5 กม. ขยายเป็น 10 กม. อัตโนมัติและแจ้งผู้ใช้) และแต่ละที่พักมีสถานที่เที่ยวในรัศมี 30 กม. ของตัวเอง การ์ดที่พักแสดงที่ใกล้สุดประมาณ 3 แห่ง กด "ดูทั้งหมด" เพื่อเปิดรายการเต็ม ระบบไม่ตั้งที่พักให้จนกว่าผู้ใช้เลือกเอง

ดึงสถานที่ทั้งพื้นที่จาก OpenStreetMap ครั้งเดียว แล้วคำนวณระยะของแต่ละที่พักในเครื่อง เพื่อไม่ให้เรียกบริการสาธารณะซ้ำหลายครั้ง

## แผนที่และเส้นทาง

เส้นตรงจากที่พักไปแต่ละสถานที่ พร้อมปุ่ม "นำทางด้วย Google Maps" และปุ่ม "ดูรีวิวที่ Google Maps" (ลิงก์ ไม่ใช้ API key)

## ข้อมูล

- OpenStreetMap (Nominatim, Overpass) ตอนค้น ต้องมีอินเทอร์เน็ต ได้แค่ชื่อ ประเภท พิกัด
- สถานที่ที่ตรวจที่มาแล้ว 307 แห่ง (ใน `services/places/data/`) ติดป้ายแยก ดู `docs/DATA_SOURCES.md`

## ผู้ใช้และการบันทึก

ล็อกอินแล้วบันทึกได้: ประวัติที่พักที่ค้น สถานที่โปรด ประวัติแชต ผู้ที่ไม่ล็อกอินใช้ค้นและแชตได้แต่ไม่บันทึก

## ตัวตรวจผลค้น

เขียนแยกจากตัวค้น ตรวจว่าทุกจุดอยู่ใน 30 กม. เรียงถูก ไม่ซ้ำ และมีอยู่จริงในแหล่งข้อมูล ผลต้องผ่านตัวตรวจก่อนแสดง

## นอกขอบเขต

จองที่พัก ชำระเงิน แสดงราคาหรือค่าเข้า รีวิวหรือคะแนนในระบบ ตัวจัดแผนรายวัน (ของเสริมถ้าเวลาเหลือ) เส้นทางถนนจริง
