# DEMO_SCRIPT: สคริปต์เดโม

เดโมประมาณ 6 นาที ต่อจากสไลด์ (ประมาณ 6 นาที) รวมราว 12 นาที เหลือเวลาตอบคำถาม

ช่องที่เขียน `[ตัวเลข: ...]` ต้องใส่จากผลวัดจริงเท่านั้น ยังไม่มีผลให้เว้นไว้หรือตัดประโยคนั้นออก ห้ามประมาณ

## เตรียมก่อนเดโม

| สิ่งที่ต้องเช็ก | วิธีเช็ก |
|---|---|
| เว็บเปิดได้ | เปิดหน้าแรก ค้นที่พัก 1 แห่ง เห็นรายการและแผนที่ |
| API พร้อม | `GET /api/health` ตอบ ok และมี `rag.docs` |
| โหมดแชต | ดูใน `/api/health` ว่า `rag.llm` เป็น true หรือ false แล้วเลือกบทพูดในฉาก 4 ให้ตรง |
| บัญชีเดโม | สมัครไว้ก่อน 1 บัญชี มีสถานที่โปรด 2-3 แห่ง และประวัติค้น 1-2 รายการ |
| แท็บสำรอง | เปิดวิดีโอเดโมไว้ในอีกแท็บ |
| หน้าจอ | ซูมเบราว์เซอร์ 110-125% ให้คนหลังห้องอ่านได้ ปิดการแจ้งเตือน |

## บทพูด

**ฉาก 1 ค้นจากชื่อที่พัก**
"สมมติว่าเราจองที่พักในเชียงใหม่ไว้แล้ว พิมพ์ชื่อที่พักลงไป ระบบจะหาที่เที่ยวและคาเฟ่ในรัศมีไม่เกิน 30 กิโลเมตร แล้วเรียงจากใกล้ไปไกล ระยะที่เห็นเป็นระยะเส้นตรง ไม่ใช่ระยะขับรถ ถ้าจะไปจริงกดปุ่มนำทาง ระบบจะเปิด Google Maps ให้ดูเส้นทาง"

**ฉาก 2 ใช้ได้ทุกจังหวัด**
"ลองเปลี่ยนไปจังหวัดอื่น ระบบใช้ได้ทั้ง 77 จังหวัด ข้อมูลมีสองแบบ แบบแรกคือสถานที่ที่เราตรวจที่มาเองแล้ว มีป้ายบอก แบบที่สองมาจาก OpenStreetMap ซึ่งได้แค่ชื่อ ประเภท และพิกัด เราแยกป้ายให้เห็นชัด และใส่ที่มาตามสัญญาอนุญาต"

**ฉาก 3 ยังไม่ได้จอง**
"ถ้ายังไม่ได้จองที่พัก ปักหมุดตรงย่านที่สนใจ ระบบหาที่พักรอบหมุดก่อน 5 กิโลเมตร ถ้าไม่มีจะขยายเป็น 10 และบอกผู้ใช้ แต่ละที่พักมีรายการที่เที่ยวรอบตัวเอง ช่วยเทียบได้ว่าพักที่ไหนใกล้ที่ที่อยากไป ระบบไม่เลือกที่พักให้เอง ผู้ใช้เป็นคนเลือก"

**ฉาก 4 แชต (เลือกบทตามโหมดที่เช็กไว้)**
- ถ้า `rag.llm` เป็น true: "แชตใช้เครื่องมือค้นตัวเดียวกับหน้าค้นหา ผลค้นต้องผ่านตัวตรวจก่อน แล้วระบบดึงข้อความจากบทความ Wikipedia ของสถานที่ในผลนั้นมาให้โมเดลเรียบเรียง ทุกประโยคต้องอ้างที่มา ใต้คำตอบจะเห็นรายการที่มาและสัญญาอนุญาต ถ้าคำตอบไม่ผ่านด่านตรวจ ระบบตอบแบบกฎแทน"
- ถ้า `rag.llm` เป็น false: "ตอนนี้แชตตอบด้วยกฎ ไม่ได้ใช้โมเดลภาษา แต่ใช้เครื่องมือค้นและตัวตรวจชุดเดียวกับหน้าค้นหา จึงไม่มีชื่อหรือระยะที่ระบบแต่งขึ้นเอง" (ห้ามพูดว่าใช้ LLM ในโหมดนี้)
- ลองถามราคาหรือค่าเข้า: "ระบบตอบตรงๆ ว่าไม่มีข้อมูลนี้ เพราะเราไม่แสดงตัวเลขที่ไม่มีแหล่งยืนยัน"

**ฉาก 5 หน้ารายละเอียดและหน้าจังหวัด**
"กดที่สถานที่จะเห็นหน้ารายละเอียด ส่วนที่ไม่มีข้อมูลจริงจะไม่แสดงเลย ไม่เติมคำเดา ด้านล่างบอกที่มาและวันที่ตรวจ หน้าจังหวัดรวมสถานที่ที่ตรวจแล้วของจังหวัดนั้น แยกตามหมวด"

**ฉาก 6 ทริปของฉัน**
"ผู้ที่ล็อกอินจะมีประวัติที่พักที่เคยค้น สถานที่โปรด และประวัติแชต ผู้ใช้ลบข้อมูลของตัวเองได้ทั้งหมด รวมถึงลบบัญชี ส่วนคนที่ไม่ล็อกอินก็ใช้ค้นและแชตได้ แค่ระบบไม่บันทึกอะไร"

## ตัวเลขที่จะพูด

ผลวัดแชตกับ LLM จริงจาก `docs/RAG_EVAL.md` (รอบที่ 3, 2026-11-02, claude-sonnet-5-5, 200 คำถาม) ห้ามใช้ตัวเลขจากการรันแบบ `--mock`

| เรื่อง | ค่า |
|---|---|
| คลังมีคำตอบ: LLM ตอบและผ่านด่านตรวจ | ประมาณ 84-86% (รอบล่าสุด 137 จาก 160) |
| ตัวค้นคืนเจอก้อนที่ถูกใน 3 อันดับแรก | 98.8% (158 จาก 160) |
| นอกขอบเขต ตอบว่าไม่ทราบ | 20/20 |
| ถามราคา รีวิว จอง ปฏิเสธ | 12/12 |
| พยายามสั่งระบบ | 8/8 |

ตอนพูดต้องบอกทุกครั้ง:
- คำถามทั้งหมดเขียนโดยทีมเอง ไม่ใช่ผู้ใช้จริง
- ข้อที่ไม่ผ่านรอบล่าสุด 23 ข้อ ระบบถอยไปตอบแบบกฎ ไม่ได้ตอบผิด และไม่มีคำตอบที่ไม่ผ่านด่านหลุดถึงผู้ใช้
- ข้อนอกขอบเขต ราคา และการสั่งระบบ ส่วนใหญ่จัดการด้วยกฎ จึงวัดความปลอดภัยของทั้งระบบ ไม่ใช่ว่า LLM ต้านเองได้
- วัดซ้ำหลายรอบ ผลต่างกันเล็กน้อย จึงรายงานเป็นช่วง

## ถ้าถูกถาม

- **ทำไมไม่แสดงราคาหรือค่าเข้า:** ไม่มีแหล่งทางการที่เปิดให้ใช้ ตัวเลขที่ผิดทำให้ผู้ใช้ตัดสินใจพลาด จึงไม่แสดง
- **ข้อมูลจริงหรือไม่:** สถานที่ที่ตรวจแล้วมีลิงก์ที่มาทุกแห่ง ส่วน OSM ได้แค่ชื่อ ประเภท พิกัด ไม่ครบทุกร้าน และใครก็แก้ได้ ระบบติดป้ายไว้
- **ระยะแม่นไหม:** เป็นเส้นตรง ไม่ใช่ระยะขับรถ มีปุ่มนำทางเพื่อดูเส้นทางจริง
- **กันแชตพูดมั่วอย่างไร:** สถานที่ที่พูดถึงต้องมาจากผลค้นที่ผ่านตัวตรวจ ข้อความจาก LLM ต้องผ่านด่านตรวจด้วยโค้ด (ชื่อ ระยะ รหัสที่มา คำต้องห้าม) ไม่ผ่านก็ตอบแบบกฎแทน
- **ถ้าไม่มีอินเทอร์เน็ต:** ข้อมูล OSM มีสแนปช็อตที่ดึงไว้ล่วงหน้า แชตถอยไปโหมดกฎ
- **ใช้ข้อมูลคนอื่นถูกลิขสิทธิ์ไหม:** OSM ใส่ © OpenStreetMap contributors (ODbL) ข้อความ Wikipedia แสดงที่มาและ CC BY-SA 4.0 ใต้คำตอบ

## แผนสำรอง

- เว็บหรือเน็ตล่ม: เปิดวิดีโอเดโมที่อัดไว้ แล้วพูดตามบทเดิม
- แชต LLM ช้าหรือล้ม: ระบบตอบโหมดกฎเอง พูดตามบทโหมดกฎ
- ค้นจังหวัดที่เตรียมไว้แล้วไม่เจอ: ใช้เชียงใหม่ซึ่งข้อมูลครบที่สุด
