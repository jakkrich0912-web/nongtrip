# DEMO_SCRIPT: สคริปต์เดโม

เวลาเดโมประมาณ 5-6 นาที (ร่าง ปรับเมื่อระบบพร้อม)

| ฉาก | ทำอะไร | ต้องโชว์ |
|---|---|---|
| 1 | พิมพ์ชื่อที่พักจริงในเชียงใหม่ | รายการเรียงใกล้ไปไกล แผนที่ เส้นตรง ปุ่มนำทาง |
| 2 | ค้นที่พักในจังหวัดอื่นที่ไม่ใช่เชียงใหม่ | ใช้ได้ทั้งประเทศ (ข้อมูลจาก OSM ติดป้าย) |
| 3 | ยังไม่ได้จอง: ปักหมุดบนแผนที่ | รายการที่พักรอบหมุด การ์ดแต่ละที่พักมีที่เที่ยวของตัวเอง |
| 4 | แชตบอท: "แถวนี้มีคาเฟ่อะไรบ้าง" | ผลตรงกับหน้าค้นหา เห็นขั้นตอนเรียกเครื่องมือ |
| 5 | ล็อกอิน แล้วเปิดประวัติและสถานที่โปรด | ข้อมูลผูกกับบัญชี |

## ถ้าถูกถาม

- ทำไมไม่แสดงราคาหรือค่าเข้า: ไม่มีแหล่งทางการที่เปิดให้ใช้ ตัวเลขที่ผิดทำให้ผู้ใช้ตัดสินใจพลาด จึงไม่แสดง
- ข้อมูลจริงหรือไม่: OSM ได้แค่ชื่อ ประเภท พิกัด ไม่ครบทุกร้าน ใครก็แก้ได้ ระบบแจ้งไว้
- ระยะที่แสดงแม่นไหม: เป็นเส้นตรง ไม่ใช่ระยะขับรถ มีปุ่มนำทางเพื่อดูเส้นทางจริง

## แผนสำรอง
