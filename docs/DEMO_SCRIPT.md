# DEMO_SCRIPT: สคริปต์เดโม

เดโมประมาณ 7 นาทีครึ่ง ต่อจากสไลด์ (ประมาณ 6 นาที) รวมราว 13 นาที เหลือเวลาตอบคำถาม

ช่องที่เขียน `[ตัวเลข: ...]` ต้องใส่จากผลวัดจริงเท่านั้น ยังไม่มีผลให้เว้นไว้หรือตัดประโยคนั้นออก ห้ามประมาณ

## เตรียมก่อนเดโม

| สิ่งที่ต้องเช็ก | วิธีเช็ก |
|---|---|
| โค้ดที่ใช้เดโม | เดโมจาก `main` หลัง merge `develop` เข้า `main` แล้ว รีบิลด์ `docker compose up -d --build --wait` |
| เว็บเปิดได้ | เปิดหน้าแรก ค้นที่พัก 1 แห่ง เห็นรายการและแผนที่ |

| ธีม | เริ่มที่โหมดสว่าง (ปุ่ม ☀/☾ ที่หัวเว็บ) โหมดมืดเก็บไว้โชว์ตอนท้าย |

เลือกที่พักและจังหวัดที่จะเดโมจากจังหวัดที่มีสแนปช็อต OSM (`services/places/data/osm_snapshot/`) และลองค้นจริงก่อนวันเดโมทุกคำ เน็ตห้องเดโมไม่ดีก็ยังค้นได้

## บทพูด

**ฉาก 1 ค้นจากชื่อที่พัก**
"สมมติว่าเราจองที่พักในเชียงใหม่ไว้แล้ว พิมพ์ชื่อที่พักลงไป ระบบจะหาที่เที่ยวและคาเฟ่ในรัศมีไม่เกิน 30 กิโลเมตร แล้วเรียงจากใกล้ไปไกล ระยะที่เห็นเป็นระยะเส้นตรง ไม่ใช่ระยะขับรถ อยากได้แค่ใกล้ ๆ กดตัวกรองรัศมีได้ ถ้าจะไปจริงกดปุ่มนำทาง ระบบจะเปิด Google Maps ให้ดูเส้นทาง"

**ฉาก 2 ใช้ได้ทุกจังหวัด**
"ลองเปลี่ยนไปจังหวัดอื่น ระบบใช้ได้ทั้ง 77 จังหวัด ข้อมูลมีสองแบบ แบบแรกคือสถานที่ที่เราตรวจที่มาเองแล้ว มีป้ายบอก แบบที่สองมาจาก OpenStreetMap ซึ่งได้แค่ชื่อ ประเภท และพิกัด เราแยกป้ายให้เห็นชัด และใส่ที่มาตามสัญญาอนุญาต ข้อมูล OpenStreetMap ของหลายจังหวัดดึงเก็บไว้ล่วงหน้า เน็ตช้าก็ยังค้นได้"

**ฉาก 3 ยังไม่ได้จอง**
"ถ้ายังไม่ได้จองที่พัก ปักหมุดตรงย่านที่สนใจ ระบบหาที่พักรอบหมุดก่อน 5 กิโลเมตร ถ้าไม่มีจะขยายเป็น 10 และบอกผู้ใช้ แต่ละที่พักมีรายการที่เที่ยวรอบตัวเอง ช่วยเทียบได้ว่าพักที่ไหนใกล้ที่ที่อยากไป ระบบไม่เลือกที่พักให้เอง ผู้ใช้เป็นคนเลือก"

## ตัวเลขที่จะพูด

ผลวัดแชตกับ LLM จริงจาก `docs/RAG_EVAL.md` (รอบที่ 3, 2026-11-02, claude-sonnet-5-5, 200 คำถาม) ห้ามใช้ตัวเลขจากการรันแบบ `--mock`

แชตเปลี่ยนไปหลังรอบที่ 3 (#57 ตอบนอกเรื่อง ค้นรอบสถานที่ที่ถามถึง และ #66 ถ้า merge) ถ้าวัดรอบใหม่ทันก่อนเดโม ให้ใช้ตัวเลขรอบใหม่ทั้งตาราง ถ้าไม่ทัน ให้บอกว่าตัวเลขนี้วัดก่อนการเปลี่ยนแปลงล่าสุด

| เรื่อง | ค่า |
|---|---|
| คลังมีคำตอบ: LLM ตอบและผ่านด่านตรวจ | ประมาณ 84-86% (รอบล่าสุด 137 จาก 160) |
| ตัวค้นคืนเจอก้อนที่ถูกใน 3 อันดับแรก | 98.8% (158 จาก 160) |
| นอกขอบเขต ตอบว่าไม่ทราบ | 20/20 |
| ถามราคา รีวิว จอง ปฏิเสธ | 12/12 |
| พยายามสั่งระบบ | 8/8 |

ตอนพูดต้องบอกทุกครั้ง:
- คำถามทั้งหมดเขียนโดยทีมเอง ไม่ใช่ผู้ใช้จริง
- ข้อที่ไม่ผ่านรอบล่าสุด 23 ข้อ ระบบถอยไปตอบแบบกฎ ไม่ได้ตอบผิด และไม่มีคำตอบที่ไม่ผ่านด่านหลุดถึงผู้ใช้
- ข้อนอกขอบเขต ราคา และการสั่งระบบ ส่วนใหญ่จัดการด้วยกฎ จึงวัดความปลอดภัยของทั้งระบบ ไม่ใช่ว่า LLM ต้านเองได้
- วัดซ้ำหลายรอบ ผลต่างกันเล็กน้อย จึงรายงานเป็นช่วง

## ถ้าถูกถาม

- **ทำไมไม่แสดงราคาหรือค่าเข้า:** ไม่มีแหล่งทางการที่เปิดให้ใช้ ตัวเลขที่ผิดทำให้ผู้ใช้ตัดสินใจพลาด จึงไม่แสดง
- **ข้อมูลจริงหรือไม่:** สถานที่ที่ตรวจแล้วมีลิงก์ที่มาทุกแห่ง ส่วน OSM ได้แค่ชื่อ ประเภท พิกัด ไม่ครบทุกร้าน และใครก็แก้ได้ ระบบติดป้ายไว้
- **ระยะแม่นไหม:** เป็นเส้นตรง ไม่ใช่ระยะขับรถ มีปุ่มนำทางเพื่อดูเส้นทางจริง
- **กันแชตพูดมั่วอย่างไร:** สถานที่ที่พูดถึงต้องมาจากผลค้นที่ผ่านตัวตรวจ ข้อความจาก LLM ต้องผ่านด่านตรวจด้วยโค้ด (ชื่อ ระยะ รหัสที่มา คำต้องห้าม) ไม่ผ่านก็ตอบแบบกฎแทน
- **ถ้าไม่มีอินเทอร์เน็ต:** ถ้าเน็ตหรือ OpenStreetMap มีปัญหา ผลที่เห็นอาจน้อยลง ระบบจะแจ้งผู้ใช้หรือให้ปักหมุดบนแผนที่แทน ถ้าเน็ตของห้องเดโมล่ม ให้เปิดวิดีโอสำรอง
- **ถ้าผู้ให้บริการ LLM ล่มหรือเครดิตหมดกลางเดโม:** แชตถอยไปตอบแบบกฎเอง ไม่ขึ้น error ถ้าตั้ง `LLM_FALLBACK` ไว้ ระบบลองผู้ให้บริการสำรอง (Gemini, Grok, OpenAI) ก่อน
- **กันคนยิงระบบรัว ๆ อย่างไร:** จำกัดแชต 20 ครั้งต่อนาทีต่อ IP สมัครบัญชีไม่เกิน 20 ครั้งต่อชั่วโมงต่อ IP และเดารหัสผ่านผิด 5 ครั้งต้องรอ เราเคยเจอช่องที่ปลอม IP หลบตัวจำกัดได้ ตอนทดสอบเจาะระบบเอง แล้วแก้แล้ว (#63)
- **ออกจากระบบแล้วปลอดภัยไหม:** เซสชันเก็บฝั่งเซิร์ฟเวอร์ กดออกจากระบบแล้วคุกกี้เดิมใช้ไม่ได้ทันที เปลี่ยนรหัสผ่านแล้วอุปกรณ์อื่นถูกออกจากระบบทั้งหมด และสั่งออกจากระบบอุปกรณ์อื่นได้เองในหน้าตั้งค่าบัญชี
- **รู้ได้ยังไงว่าระบบยังทำงานถูก:** เทสต์ Python 639 ข้อ หน้าเว็บ 133 ข้อ และเทสต์ใช้งานจริงผ่านเบราว์เซอร์ 19 ข้อ รันอัตโนมัติทุก PR ใน CI ตอนใช้งานจริงดูได้จากแดชบอร์ดผู้ดูแล
- **รหัสผ่านเก็บอย่างไร:** แฮชด้วย scrypt พร้อม salt ต่อผู้ใช้ เซสชันเป็นคุกกี้ที่เซ็นด้วย HMAC ไม่มีรหัสผ่านจริงในฐานข้อมูล
